# MacroPad Enclosure

This is a 3D modelled enclosure for the MacroPad PCB project I designed in week 1.

It is made of two parts - a base, which the PCB will attach to with threaded inserts and M3 screws, and a lid, which will magnetically snap on top of the box (in case I need to fix anything).

I think it looks pretty cool!
